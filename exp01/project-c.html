Principles

  • Few, flexible components. Fewer parts covering more cases.
  • Tokens first. Decisions live in tokens, not in components.
  • Built with engineering. Every component shipped in code and Figma together.

Adoption and governance

A system fails without a process. Sample workflow:

  1. Teams request a component in a shared channel
  2. I review it against existing parts
  3. Design and code are built together
  4. Release notes go out every two weeks
